# Intune Sample Prompts

Ready-to-use Microsoft Security Copilot prompts for common Intune administration, investigation, and endpoint security scenarios.

## Prompt Collection

- [Intune Sample Prompts](Intune%20Sample%20Prompts.md)

## Usage Order

1. Choose the prompt surface identified in the sample: Copilot Chat, Explorer, policy context, or Device query.
2. Replace values in braces, such as `{DeviceNameOrId}`, with values from your environment.
3. In Copilot Chat or Explorer, select the matching built-in suggestion and complete any requested parameters.
4. Validate the results against authoritative Intune records before taking administrative action.

For a guided investigation workflow, see the [Device Investigation Guide](../Embedded%20Experiences/Device%20Investigation%20Guide.md).
